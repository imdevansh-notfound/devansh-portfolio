# Devansh Tiwari Portfolio

A responsive React 19 + TypeScript portfolio built with Vite, Tailwind CSS, Framer Motion, React Router, and Lucide.

## Run locally

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

## Personalize before publishing

- Replace the clearly labelled project and certificate entries in `src/data/portfolio.ts`.
- Put an actual resume at `public/resume.pdf` to enable the download CTA.
- Connect the contact form to a form service or backend; it intentionally remains a visible local demo rather than pretending to send mail.
- Add project images as optimized assets when real projects are available.

The content does not claim unprovided experience, achievements, projects, or credentials.
